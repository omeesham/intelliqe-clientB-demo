## Authentication

### TC-001 — Verify successful login with valid credentials redirects to dashboard
**Feature:** User Login · **Priority:** P0 · **Type:** positive · **Severity:** Critical

Confirms a registered user with valid credentials can authenticate via the login form and land on the dashboard. This is the primary gateway flow; its failure blocks all authenticated access.

**Precondition:** The OrangeHRM demo login page is reachable at the login URL. A valid registered account exists with username 'Admin' and password 'admin123'.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: The login form is displayed with a Username field, a Password field, and a 'Login' button
2. Enter 'Admin' into the field labelled 'Username' → Expected: The Username field shows 'Admin'; no validation error appears
3. Enter 'admin123' into the field labelled 'Password' → Expected: The Password field shows masked characters; no validation error appears
4. Click the 'Login' button → Expected: The user is redirected to the dashboard URL (.../dashboard/index) and the 'Dashboard' heading is visible

**Expected Result:** The user is authenticated and lands on the dashboard with a valid session established.

**Tags:** smoke, regression, auth
