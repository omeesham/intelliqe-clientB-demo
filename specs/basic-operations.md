## Authentication

### 1. Verify successful login with valid credentials redirects to dashboard
**Feature:** User Login · **Priority:** P0 · **Type:** positive

**Precondition:** The OrangeHRM demo login page is reachable at the login URL. A valid registered account exists with username 'Admin' and password 'admin123'.

**Steps:**

1. Navigate to https://opensource-demo.orangehrmlive.com/web/index.php/auth/login → Expected: The login form is displayed with a Username field, a Password field, and a 'Login' button
2. Enter 'Admin' into the field labelled 'Username' → Expected: The Username field shows 'Admin'; no validation error appears
3. Enter 'admin123' into the field labelled 'Password' → Expected: The Password field shows masked characters; no validation error appears
4. Click the 'Login' button → Expected: The user is redirected to the dashboard URL (.../dashboard/index) and the 'Dashboard' heading is visible

**Expected Result:** The user is authenticated and lands on the dashboard with a valid session established.

### 2. Verify 'Required' message appears below Username when submitted empty
**Feature:** Field Validation · **Priority:** P1 · **Type:** negative

**Precondition:** The login page is loaded and both fields are empty.

**Steps:**

3. Enter 'admin123' into the 'Password' field → Expected: The Password field shows masked characters
4. Click the 'Login' button → Expected: A 'Required' validation message is displayed directly below the Username field and the form is not submitted

**Expected Result:** The user remains on the login page with a 'Required' message under the Username field.

**Steps:**

1. Ensure no active session by clearing cookies or using a fresh browser context → Expected: No session cookie is present

**Expected Result:** Unauthenticated access to the dashboard is redirected to the login page.
